## 免实名和免备案，到底是不是一回事

不是。这两条规则管的对象完全不同，只是碰巧在境外服务器上同时成立。

**实名认证管的是“你是谁”。** 下单买服务器时核验购买者身份，提交身份证、护照或营业执照。**ICP 备案管的是“这个网站能不能在中国境内公开访问”。** 域名解析到中国大陆境内服务器，必须在工信部系统完成备案并拿到备案号，否则 80/443 端口会被机房系统自动拦截打回。

所以三种组合各自成立：

- **境外机房**（香港、美国、日本、新加坡）：通常既不要实名也不要备案，邮箱注册就能下单，域名解析后直接访问。
- **国内机房 + 对外网站**：既要实名也要备案，两条都躲不掉。
- **国内机房 + 非网站业务**：只跑内部数据库、API 接口、AI 训练、游戏后端、自动化测试，不绑域名对外渲染网页，必须实名，但不涉及备案。

网上常见的逻辑错误有两个：一是以为“免实名所以免备案”，二是以为“免备案必定免实名”。免备案的根源是机房物理位置在境外，和你交没交身份证没关系；反过来，部分境外服务商出于自身合规要求仍会做身份核验，这也不影响它境外节点免备案的性质。

还有一条常被搞混：**备案跟主机位置绑定，跟域名注册在哪无关。** 域名解析到境内主机就要备案，解析到香港或海外主机就不用；域名只拿来收邮件、不做网站，那国内国外空间都不需要备案。

时间成本是多数人搜“免备案服务器”的真正原因。公开的服务商资料里，备案周期有两种说法：一种是 7–20 个工作日，遇到节假日顺延，涉及医疗、金融、出版这类前置审批的行业更久；另一种是 20 天以上。两种口径都指向同一件事：等号下来，业务窗口可能已经过了。

再补一句合规边界。用境外服务器托管网站本身不违反中国法律，境外机房不归工信部管。但面向中国大陆用户提供经营性服务（电商、SaaS、付费内容），仍要遵守国内相关业务法规。备案和合规是两件事，免了备案不等于免了经营资质。另外，**免备案也不等于免内容审核**，境外机房同样受所在地法律约束，违法违规内容照样封停。

## 市场上说的“国内免备案服务器”是怎么回事

搜这个词会看到一些服务商以“国内免备案服务器”为卖点，页面列出北京口径的机房资源、防御带宽、99.99% 连通率，价格从六百到一千六一个月。

监管口径是另一回事：境内机房对外提供网站服务必须备案，未备案域名解析到境内 IP，80/443 会被拦截。这两者对不上。

碰到“国内免备案”的宣传，有三个可执行的核实动作：

1. **问机房实际所在地。** 具体到城市和机房名称，不要接受“国内优质节点”这种说法。
2. **要测试 IP 查归属。** 用 whois 或 ASN 查询看 IP 注册在哪个国家、哪个运营商。
3. **看是否要求实名。** 境内资源按规定必须实名认证。既说机房在境内、又完全不要实名、还能免备案，这三个条件凑在一起本身就说明有问题。

如果核实下来机房确实在境内，那“免备案”这个表述存在合规风险，网站随时可能被打回。想稳，就把机房放到境外，这是唯一没有争议的做法。
